# AfriTalent 
Projet fil rouge — Plateforme de mise en relation entre freelances africains et 
clients. 
Auteur : Khady Seck Mbaye 
Promotion : L1 IAGE — ISI

# Description 

AfriTalent est une plateforme web qui met en relation les freelances africains et les entreprises à la recherche de compétences professionnelles. Le site permet de découvrir différents services, consulter des témoignages, connaître les tarifs et contacter facilement l'équipe. L'objectif est de faciliter l'accès aux opportunités professionnelles et de valoriser les talents africains à l'échelle internationale.

# Technologies utilisées

* HTML5
* CSS3
* JavaScript
* Bootstrap 5
* Bootstrap Icons
* Font Awesome
* Git & GitHub

# Fonctionnalités principales

* Navigation responsive adaptée aux mobiles, tablettes et ordinateurs.
* Mode sombre / mode clair.
* Animation des compteurs statistiques.
* Effets d'apparition au défilement (scroll animations).
* Carousel de témoignages avec Bootstrap.
* Formulaire de contact avec validation JavaScript.
* Bouton de retour en haut de page.
* Design moderne basé sur Bootstrap.

# Instructions pour lancer le projet localement

1. Télécharger ou cloner le dépôt GitHub.
2. Ouvrir le dossier du projet dans Visual Studio Code.
3. Vérifier que tous les fichiers sont présents (HTML, CSS, JS, images).
4. Ouvrir le fichier `index.html` dans un navigateur web.
5. Ou utiliser l'extension **Live Server** pour lancer le site localement.
